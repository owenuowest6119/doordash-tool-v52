## Overview

DoorDash Tool is a locally operated HTML application for organizing operational performance work. The project gives merchants a focused place to track results, compare quarterly activity, and work with metrics through an integrated calculator.

Release 5.2 is intended for merchant workflows, training activities, and sales support. Because the interface is responsive and delivered as an HTML application, it fits situations that call for a lightweight browser tool rather than a larger desktop application.
